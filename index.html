How it works

  1. The project's root key names a publisher key in a readonly Arkiv entity.
  2. The publisher publishes its official sites, handles and contracts as readonly Arkiv entities with a 30-day lease, renewed on every deploy.
  3. Your check is one Arkiv query that keeps only entities whose immutable $creator is one of those keys. Names and labels anyone can write are never trusted.
  4. New endpoints wait 48 hours. Incidents can only restrict, are handed to a burn address so no key can delete them, and anyone can keep them alive.

No server, no indexer: this page talks straight to Arkiv's Tiramisu RPC. Same check from a terminal: npx github:Ryugi62/officially check https://app.demo-swap.example
